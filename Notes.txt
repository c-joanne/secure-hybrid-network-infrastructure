Setting Up SSL VPN for Remote Clients

FW-A
User & Authentication 
> User Definition > Create New >
	Local User > User: User1, Password: Abc@1234 > Save

CLI Console 
> Configure:
config system settings
set gui-sslvpn enable
end
> Refresh page
VPN > SSL-VPN Settings > Create New
	> Connection Settings: 
		Listen on Interfaces: WAN1
		Listen on Port: 10443
	> Tunnel Mode Client Settings:
		Specify > Create > + Address > Name: SSLVPN_POOL, Type: IP Range, IP Range: 192.168.20.10-192.168.20.50 > OK 
		> Select the pool we just made

VPN > SSL-VPN Portals > Create New
	> Name: full-access > Tunnel Mode: Enabled > Web Mode: Off > IP Pools: SSLVPN_Pool > OK

VPN > SSL-VPN Settings > Refresh Page
	> Authentication/Portal Mapping: Edit "All Other Users/Groups" > Portal: full-access > OK 
		> Create New
			> Users/Groups: User1, Portal: full-access > OK > APPLY

			--------------------------------------------

Firewall Policy for SSL VPN
Policy & Objects > Create New
	Name: SSLVPN-to-LAN, Incoming Interface: ssl.root, Outgoing Interface: internal, Source: all and User1, Destination+Service: all, Action: Accept, NAT: Disabled
		> SSL-VPN Settings > Server Certificate: Fortinet_Factory > Apply
	Back to SSLVPN-to-LAN > Apply
	
			--------------------------------------------
